# Homebrew Tap for sphragis-oss

Casks for the [sphragis-oss](https://github.com/sphragis-oss) projects: agent
tooling and compliance infrastructure, with first-class support for
**Claude Code**.

## Install

```sh
brew tap sphragis-oss/sphragis
brew install --cask <name>
```

Or in a single step, without tapping first:

```sh
brew install --cask sphragis-oss/sphragis/<name>
```

## Casks

| Cask | What it is | Project |
| --- | --- | --- |
| `choragos` | Secure multi-agent development orchestrator TUI | [choragos](https://github.com/sphragis-oss/choragos) |
| `choragos-desktop` | Desktop app for the choragos orchestrator | [choragos](https://github.com/sphragis-oss/choragos) |
| `isthmos` | Local context-compression layer for agent tool outputs | [isthmos](https://github.com/sphragis-oss/isthmos) |
| `sphragis` | EU AI Act compliance gateway: local PII redaction and a tamper-evident audit log | [sphragis](https://sphragis.eu) |

## macOS only

Homebrew Casks are macOS-only, so this tap is too. On Linux, use each
project's install script, `go install`, or build from source. See the
project README.

## How these are published

`choragos`, `isthmos` and `sphragis` are generated by GoReleaser on each
release of their project and carry a `DO NOT EDIT` header. Changes to them
belong in the corresponding project's `.goreleaser.yaml`, not here.

`choragos-desktop` is maintained in this repository; its version and
checksum are bumped by the choragos desktop release workflow.
